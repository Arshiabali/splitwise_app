# splitwise_app
SplitEase is a modern student expense splitter web app that helps friends split bills easily without complicated calculations. Users can add friends, track shared expenses, view balances, and get smart settlement suggestions instantly.

Features :-
Add & manage friends
Split expenses among selected people
Automatic balance calculation
Smart settle-up suggestions
Expense categories
Responsive modern UI
Animated dark theme

Tech Stack:-
HTML
CSS
JavaScript
How It Works:-
Add friends
Add expenses
Choose who paid
Select people to split with
View balances & settlements

Algorithms Used:-
Expense sharing logic
Minimum Cash Flow algorithm
Future Improvements
Local storage support

Authentication:-
Export reports
Real-time syncing
